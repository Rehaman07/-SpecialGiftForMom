# SpecialGiftForMom

Make this Mother's Day unforgettable with a magical, interactive digital surprise. More than just a card, it is a playful journey where Mom solves three charming puzzles to unlock secret doors. Each click brings her closer to the final golden chest.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env.local` if you use Gemini-powered features.
3. Run the app:
   `npm run dev`
4. Build the app:
   `npm run build`
